    Overview

    The whole tool lives in one Python file, regquery.py. It behaves differently depending on where it runs.

    • On your Windows PC it scans the registry itself and rescans every few seconds, so the dashboard always shows live data.
    • On Streamlit Cloud there is no Windows registry, so you upload a regquery.txt file instead and get the same charts and tables.

    What you get

    • Counts of total, blacklisted and clean software.
    • A red alert listing every blacklisted name.
    • Live alerts when software is added or removed between scans.
    • A donut chart, a bar chart and a progress bar.
    • A searchable, filterable table of every entry.
    • Download buttons for softwares.txt and blacklist_softwares.txt.

    Good to know. HKLM\SOFTWARE lists top-level keys, which are usually vendor or system names like Microsoft or Classes, not every installed program. For a full program list you would query HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall and read each DisplayName.

    How it works

    Every scan follows the same five steps.

    1. Run reg queryPython calls the Windows command with subprocess.
    2. Save outputThe raw text is written to regquery.txt.
    3. Extract namesEach key line is split at the last backslash.split("\\")[-1]
    4. Check blacklistNames containing any blacklist word are flagged.
    5. Show dashboardCharts, alerts, the table and text files are updated.

    Name extraction

    Only lines starting with HKEY_LOCAL_MACHINE are kept, which skips blank lines. The name is everything after the final backslash, so names with spaces like Mozilla Firefox stay whole.

    # HKEY_LOCAL_MACHINE\SOFTWARE\Mozilla Firefox  →  "Mozilla Firefox"
if line.startswith("HKEY_LOCAL_MACHINE"):
    names.append(line.split("\\")[-1])

    Blacklist check

    The check is case-insensitive and matches the word anywhere in the name.

    NordVPNlowercase nordvpncontains "vpn"? Blacklisted
    Pythonlowercase pythonno match OK

    Run it on your PC

    Install Streamlit

    Open a terminal in the project folder and run:

    python -m pip install -r requirements.txt

    Wait for the line starting with Successfully installed. Installing numpy can pause for a minute or two. Don't press Ctrl+C while it does.

    Start the app

    Either double-click run_scanner.bat, or run this command:

    python -m streamlit run regquery.py

    The dashboard opens in your browser at http://localhost:8501. Press Ctrl+C in the terminal to stop it.

    The launcher file

    run_scanner.bat moves into its own folder and starts the app through Python, so you don't need Streamlit on your PATH.

    @echo off
cd /d "%~dp0"
python -m streamlit run regquery.py
pause
    • Desktop shortcut: right-click the file and choose Send to → Desktop (create shortcut).
    • Start with Windows: press Win+R, type shell:startup, and put a shortcut in that folder.

    Using the dashboard

    The page has a sidebar of settings and a main area that updates with every scan.

    Blacklist words

    Type words separated by commas in the sidebar, for example vpn, torrent, proxy. Everything on the page updates straight away, with no rescan needed. The default is vpn, torrent.

    Live refresh

    On Windows the scan reruns on a timer. The default is every 10 seconds, the minimum is 5, and you can switch it off with the Auto refresh toggle. The timer reruns only the scan section, so your search text and filters stay as they are.

    # A fragment reruns on its own; run_every sets the timer
@st.fragment(run_every=refresh_every)
def live_view():
    software = scan_registry()
    ...

    Change alerts

    Each scan is compared with the previous one. A yellow alert lists software that appeared, and a blue one lists software that disappeared. If someone installs a VPN while the app is open, you see it at the next refresh.

    Charts

    Search, filter and download

    The search box filters the table as you type. Tick Show only blacklisted to hide clean entries. The two download buttons save the current lists as text files.

    Local mode and cloud mode

    The app checks platform.system() when it starts and picks the right mode by itself.

    On your Windows PC

    • Scans the registry directly
    • Live auto-refresh
    • Added and removed alerts
    • Saves the three text files
    • Charts, table and downloads

    On Streamlit Cloud

    • No registry, so you upload regquery.txt
    • No auto-refresh
    • No change alerts
    • Doesn't save files on the server
    • Charts, table and downloads

    Uploaded files are decoded whether they were saved as UTF-8 or UTF-16, so files made in Command Prompt or PowerShell both work.

    Push to GitHub

    Create an empty repository on github.com, then run these commands in the project folder. Replace YOUR-USERNAME with your GitHub username.

    git init
git add .
git commit -m "Software scanner with live refresh"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/software-scanner.git
git push -u origin main

    For later changes, three commands are enough:

    git add .
git commit -m "describe what you changed"
git push

    Create the app

    1. Go to share.streamlit.io and sign in with GitHub.
    2. Create a new app and choose your repository and the main branch.
    3. Set the main file path to regquery.py.
    4. Click Deploy. You get a public link after a minute or two.

    Make regquery.txt for upload

    1. Press the Windows key and type cmd.
    2. Right-click Command Prompt and choose Run as administrator.
    3. Click Yes when Windows asks for permission.
    4. Run the command below. The file appears on your Desktop.
    5. Upload it in the app's sidebar.
    reg query HKLM\SOFTWARE > %USERPROFILE%\Desktop\regquery.txt

    An administrator Command Prompt starts in C:\Windows\System32. Saving to the Desktop keeps the file out of that system folder and easy to find.
